# FRA Atlas & WebGIS Decision Support System

A Next.js interface prototype for exploring Forest Rights Act claim data on a map and dashboard.

## Overview

The interface displays sample claim records for four Indian states. The satellite timeline and change-detection API routes return fixed demonstration data; they do not process live satellite imagery or run a machine-learning model.

## Features

- Leaflet map with sample claim markers and status details
- Dashboard summaries and claim filters
- Language switching for the interface
- Demonstration satellite timeline and simulated change-detection results

## Tech Stack

- **Framework:** Next.js 15, React 19, TypeScript
- **UI:** Tailwind CSS, Radix UI
- **Mapping:** Leaflet, React Leaflet

## Getting Started

Install Node.js and npm. From the repository root:

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.
